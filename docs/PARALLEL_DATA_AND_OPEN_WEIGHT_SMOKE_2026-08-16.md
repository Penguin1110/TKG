## Method line

### Real checkpoint

The live smoke used the locally cached `Qwen/Qwen3.5-4B` checkpoint on an RTX
4090. All traversal scores came from actual causal-LM token logits.

### Comparability audit

Directly scoring each full action string is invalid for submit competition:

| Diagnostic | Result |
|---|---:|
| Action-order permutation | exact invariant |
| Opaque action-ID rename | exact invariant |
| Held-out navigation progress recall@1 | 8/8 |
| Held-out navigation progress recall@3 | 8/8 |
| Mean FOLLOW_LINK score | -0.956 |
| Mean LIST_REVISIONS score | -1.016 |
| Mean SUBMIT_SLOT score | -1.145 |
| Direct full-string submit, complete evidence | 0/4 |

Opaque action IDs were removed from scored text. Name substitutions still
changed scores by roughly 0.5 log-prob in the small diagnostic, so lexical
sensitivity remains measurable even though common names did not systematically
win.

The fixed SUBMIT penalty is handled with a probabilistically coherent
factorization:

```text
P(SUBMIT | state)
P(CONTINUE | state) * P(graph action | CONTINUE, state)
```

SUBMIT/CONTINUE uses two label rotations to cancel A/B verbalizer priors. On
the independent submission prompt-development states after the prompt fix:

```text
complete evidence -> submit: 4/4
incomplete evidence -> false submit: 0/4
```

This is development evidence, not a frozen independent gate.

Result:


The graph/action ranking and submit-vs-continue decision used real Qwen logits.
The compact answer/evidence payload was produced by a deterministic synthetic
fixture, not generated by Qwen. Therefore this establishes an open-weight
action-decoding engineering smoke, but not a complete live solver or formal
graph-integrated benchmark result.
